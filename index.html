Frequently Asked Questions

Is CampusOS completely free for university students?

Yes! CampusOS is built by students for students. There are no paywalls for notes, question papers, or peer connections.

Does this MVP persist data without a server?

Yes! All peer requests, uploaded resources, saved listings, registered events, and comments persist in browser LocalStorage. The services layer is architected for clean future backend integration (Firebase / Supabase / PostgreSQL).

How does it deploy to GitHub Pages?

All asset references use strictly relative paths and a dedicated GitHub Actions workflow automatically builds and publishes the production static site to GitHub Pages.
